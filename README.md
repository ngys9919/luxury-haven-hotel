# Luxury Haven Hotel - Booking Website

A beautiful, modern hotel room booking application with a premium design.

## 🌐 Live Website

Visit the live website at: **https://ngys9919.github.io/luxury-haven-hotel/**

## ✨ Features

- **Beautiful Landing Page** with hero section and smooth animations
- **Room Listings** with 6 luxury accommodations
- **Interactive Booking System** with date pickers and guest selection
- **My Bookings Page** to view all reservations
- **Search Functionality** to filter bookings by guest name
- **Responsive Design** that works on all devices
- **Local Storage** for data persistence

## 🚀 How to Use

1. Browse available rooms on the home page
2. Click "Book Now" on your preferred room
3. Fill in your details and select dates
4. Review the automatic price calculation
5. Confirm your booking
6. View your reservations in "My Bookings"

## 💻 Technology

- Pure HTML5, CSS3, and Vanilla JavaScript
- No frameworks or dependencies required
- Client-side data storage using localStorage
- Fully responsive design
